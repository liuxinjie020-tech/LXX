# 产出规范

本文件用于需要制作公众号长图、小红书封面或知识切片时。产出数量随大纲变化，不为了凑固定张数拆散知识点。

视觉样式以 [`../assets/reference-wechat-long-image.png`](../assets/reference-wechat-long-image.png) 为默认母版；制作前同时阅读 [`visual-style.md`](visual-style.md)。

## 1. 内容底稿

先生成供排版使用的结构化内容底稿，层级为：本期主题、学习路径、知识点标题、核心结论、2—4 条记忆要点、关键词、案例与配图计划。

- 用户给出大纲时，保持其顺序与分组。
- 用户只给逐字稿或音频时，按讲授逻辑归并重复内容，不逐句搬运口语。
- “课程记忆点”与补充背景分开表达，避免把推论包装成讲师原话。

## 2. 公众号长图

公众号长图承载完整的复习逻辑，默认包含：

1. 本期横版封面作为完整首屏，必须包含“主题＋学长/学姐形象＋建筑理论相关背景”；
2. 学习地图或知识点目录；
3. 按大纲顺序展开的知识段落；
4. 每个重点下方 2—4 张相关图片及短图注；
5. 高频比较、总结或复习方法；
6. 结尾自测题。

排版采用暖白底、黑字、橙色重点、圆角信息卡。正文不得突出卡片边界或画布；先根据实际换行计算高度，再决定画布总长。不得通过缩小到难以阅读来解决溢出。

长图顶部必须直接使用本期已经完成的横版封面，不另外拼一个相似但不一致的表头。若用户给出获认可的旧版长图，只修改其明确指出的问题，并保留已认可的内容和整体秩序。

## 3. 小红书封面

默认尺寸为 1080 × 1440。

- 主题版：人物与本期核心标题占据主要视觉面积，适合稳定的系列识别。
- 提问版：用本期真实知识冲突或记忆难点形成一个简洁疑问句，人物与问题同样突出。
- 其他元素只承担品牌识别和氛围营造，避免缩小人物和标题。
- 封面可显示期数和学长/学姐身份，但不得与主标题争抢层级。

## 4. 小红书知识切片

默认结构：

- 01：主题封面；
- 02：学习地图；
- 中间页：每个一级知识点一页；
- 最后一页：自测、比较或脱稿复述。

页数由知识点数量决定。每张卡保持品牌标识、音频提示、页码、标题、橙色副标题、图片区、记忆要点、看图反背关键词和页脚的一致结构。

若这套卡片建立在用户已确认的公众号长图之上，则把该长图和已确认封面视为内容与视觉基线：按原知识点顺序重排为语义卡，不重新研究或改写已确认结构。优先在信息密度高的模块中增加连续知识卡，确保每张卡独立可读、图像与图注不被拆开；不要把长图按固定高度裁切。

图片区按内容选择：

- 4 张图：优先 2×2 等权网格；
- 3 张图：两张并列加一张通栏，或按主体比例重新组合；
- 2 张图：等宽并列或一主一次；
- 1 张图：仅在它足够强且信息密度高时使用通栏。

图片应尽量占满卡槽。书页、地图和课件截图需裁掉无意义页边；技术图若必须完整保留，可以留出必要呼吸空间，但同页应搭配更饱满的照片或局部放大图。不得出现空白图位、加载失败图或主体缩成页面中央小点的情况。

## 5. 发布与交付文件

一个完整 episode 文件夹建议包含：

```text
EPxx_主题/
├─ EPxx_公众号长图_主题.png
├─ 小红书贴图_全套/
│  ├─ 01_封面_主题.png
│  ├─ 02_学习地图.png
│  ├─ 03...知识切片.png
│  └─ 最后一页_自测.png
├─ 小红书封面备选/
│  ├─ A_主题版.png
│  └─ B_提问版.png
├─ EPxx_小红书贴图_总览.jpg
├─ EPxx_小红书贴图.zip
├─ EPxx_配图来源清单.md
└─ 可编辑源文件/
```

若用户要求发布文案，再补充公众号引导语、小红书标题与正文。来源清单至少记录：所属知识点、图注、来源类型、原始文件或网页、授权/署名信息（如可得）、是否裁切或二次处理、是否为 AI 生成。

## 6. 最终检查表

- 封面人物和标题是否为第一视觉层级；
- 公众号首屏是否使用同一期横版封面；
- 所有知识点是否按用户大纲顺序出现；
- 每张图是否与所在知识点直接相关并能触发回忆；
- 是否仍有大块无意义白边或空图位；
- 是否有文字、图注或圆角卡片越界；
- 每张小红书卡是否为 1080 × 1440；
- 用户要求直接复用参考封面时，最终首屏是否与参考图除指定标题字段外保持一致；
- 用户要求延展参考背景时，背景是否为同源元素、对比度受控且未压住文字或图片；
- 页码、期数、学长/学姐、品牌名和音频提示是否一致；
- 总览、压缩包和来源清单是否与最终图片同步。
