# 快题图纸整理skill

将已经编号的快题图纸整理为展示成图。默认把相同主编号的图片放在同一张横向大图内，例如 `5.1.jpg`、`5.2.jpg`、`5.3.png` 输出为一张第 5 组图。

## 开始前

- 先确认用户已完成编号命名，并从文件名说明同一主编号应合并。
- 使用用户本轮提供的水印图片；不要沿用旧水印，除非用户明确要求。
- 默认将结果输出至源图目录下的 `编号整理成图`；只生成 PNG。若要覆盖已有结果，先得到用户的明确授权。
- 不在成图画面内写入原文件名、编号或额外标题；保留固定页眉 `秋季快题作品展示` 即可。

## 排版原则

- 内容完整优先：绝不通过裁切、遮罩或跨出单元格的放大来填满版面。只可移除图片最外围可确认的纯白留边，并保留安全边距。
- 在不裁切的前提下，按比例将每张图放大到所属单元格的最大尺寸。不要为了“饱满”而切掉文字、尺寸线、边框或扫描留白。
- 1 张图用整张主画面；2 张图左右并排；3 张图以左侧主图、右侧上下两张布局；4 张图用 2×2。更多图片采用尽量接近方形的网格。
- 使用白底、4800×3400 像素、300 DPI、橙色图框（`#EF6512`）、左下角 LiXiang Design 矢量 Logo。
- 用户提供的水印置于画面中心，尺寸明显但透明，不遮挡阅读；水印白底应透明化，只保留图形本身。

## 执行

运行 [scripts/render_kua_ti.py](scripts/render_kua_ti.py)：

```powershell
python scripts/render_kua_ti.py --input "<已编号图片目录>" --watermark "<本轮水印图片>" --output "<输出目录>" --overwrite
```

脚本只读取输入目录第一层中形如 `主编号.子编号.扩展名` 或 `主编号.扩展名` 的图片；其余文件不会进入成图。完成后核对输出张数是否等于主编号数量，并目视检查至少一张多图版面，重点确认没有裁切内容。
