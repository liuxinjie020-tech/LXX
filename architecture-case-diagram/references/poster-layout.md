# 图版布局规范

## 默认版式

采用竖向版面和清晰的阅读路径：标题 → 照片 → 四图分析 → 总结。四张分析图使用 2×2 网格，每张图保留相同的标题位置、边距、线宽和标注方式。

## 信息层级

1. 标题最大，项目名称次之。
2. 四个图名必须一眼可区分。
3. 图内只标注关键动作：入口、路径、轴线、庭院、公共空间、视线、体量变化等。
4. 结论使用一句完整短句，不写长段落。

## 色彩

- 黑色：建筑轮廓、结构、主要文字。
- 红色：分析动作和核心关系。
- 灰色：背景、次要体量、辅助线。
- 淡蓝/淡绿/淡黄：水体、植被、功能或场地分区。

避免使用过多颜色或装饰性图标；颜色必须承担信息区分功能。
